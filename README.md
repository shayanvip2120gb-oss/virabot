# سامانه ربات تلگرام مینی‌دوره رایگان ویرا انگلیش (Viraa English Academy)

سامانه تخصصی ثبت‌نام، احراز هویت، بررسی عضویت کانال عمومی، تولید لینک اختصاصی درخواست عضویت، صف تأیید خودکار درخواست‌های ورود به کانال خصوصی، ارسال پیام‌های انبوه زمان‌بندی‌شده، و پنل مدیریت و تحلیل قیف تبدیل.

این پروژه با **PHP خام (بدون وابستگی به فریم‌ورک‌های سنگین)**، بر پایه استانداردهای PHP 8.1+ و PDO (پشتیبانی آماده از SQLite و MySQL/MariaDB) پیاده‌سازی شده است.

---

## ۱. ویژگی‌های کلیدی سامانه

1. **جریان ثبت‌نام روان و فارسی:**
   - شروع با فرمان `/start` و ثبت منبع کمپین (Deep Link).
   - دریافت نام کاربر و شماره تماس.
   - ورود شماره به دو روش: دکمه رسمی ارسال شماره تلگرام (`request_contact`) و تایپ دستی.
   - تشخیص سطح اطمینان مالکیت شماره (`verified_ownership` در برابر `unverified_ownership`).
   - نرمال‌سازی شماره‌های همراه ایران (`09...`، `+98...`، `0098...`) و تبدیل ارقام فارسی و عربی به انگلیسی.
2. **بررسی عضویت کانال عمومی (یک‌بار برای همیشه):**
   - قابلیت فعال/غیرفعال‌سازی از تنظیمات.
   - در صورت روشن بودن، تنها یک بار در جریان فعال‌سازی بررسی می‌شود و در صورت خروج کاربر در آینده، دسترسی او لغو نمی‌شود.
   - در صورت خاموش بودن، مرحله به‌طور خودکار رد می‌شود.
3. **تولید لینک و صف تأیید درخواست ورود (`chat_join_request`):**
   - ایجاد لینک اختصاصی کانال مینی‌دوره با قابلیت `creates_join_request = true`.
   - کاربر با کلیک روی لینک درخواست عضویت می‌دهد.
   - ربات افراد واجد شرایط را از طریق صف پس‌زمینه تأیید می‌کند (`approveChatJoinRequest`).
   - در صورتی که کاربر قبل از تکمیل ثبت‌نام درخواست عضویت داده باشد، درخواست در حالت انتظار ذخیره شده و به محض تکمیل ثبت‌نام، به‌طور خودکار تأیید می‌شود.
4. **سیستم ارسال پیام انبوه (Broadcast):**
   - پشتیبانی از متن، عکس با کپشن و دکمه شیشه‌ای (Inline URL).
   - قالب متغیر `{name}` با جایگذاری امن.
   - سگمنت‌بندی مخاطبان (همه، واجدین شرایط، اعضای تأییدشده، دارای شماره تماس، منبع کمپین).
   - کنترل سرعت ارسال (Rate Limiting استاندارد تلگرام: ۲۰ تا ۳۰ پیام در ثانیه).
   - ارسال پیام تستی به مدیر قبل از انتشار.
   - کنترل‌های توقف، ادامه و لغو کمپین.
5. **پنل مدیریت وب و شاخص‌های قیف تبدیل:**
   - رابط کاربری کاملاً فارسی و راست‌به‌چپ (RTL).
   - سطوح دسترسی: مالک (Owner)، مدیر عملیاتی (Manager)، اپراتور (Operator)، تحلیلگر (Analyst).
   - نمودار قیف تبدیل و محل ریزش کاربران.
   - خروجی اکسل (CSV) با هدرهای فارسی، UTF-8 BOM، فرمت متنی شماره‌ها و ایمنی در برابر Formula Injection.
   - پایش سلامت سیستم، مصرف فایل‌های لاگ، وضعیت صف و وب‌هوک.
6. **مدیریت لاگ و کنترل حجم دیسک:**
   - چرخش خودکار فایل‌های لاگ (Rotation) در حجم ۱۰ مگابایت.
   - بودجه کلی لاگ‌ها حداکثر ۳۰۰ مگابایت.
   - پاک‌سازی اطلاعات محرمانه (عدم ذخیره توکن، شماره‌های کامل و کلمات عبور در فایل لاگ).
7. **دستورات خط فرمان (CLI):**
   - `install.php`: ساخت خودکار جداول پایگاه‌داده و مقداردهی اولیه تنظیمات.
   - `doctor.php`: بررسی جامع پیش‌نیازها، اکستنشن‌های PHP، دسترسی دایرکتوری‌ها و توکن تلگرام.
   - `worker.php`: پردازشگر دائمی صف درخواست‌ها و پیام‌های انبوه.
   - `cron.php`: زمان‌بندی چرخش لاگ‌ها و پاک‌سازی داده‌های منقضی‌شده.

## ۳. پیش‌نیازهای سرور

- سرور لینوکس (Ubuntu 22.04 LTS / Debian 12 توصیه می‌شود) یا هاست لینوکسی با دسترسی SSH یا وب‌سرور استاندارد.
- زبان PHP نسخه ۸.۱ یا بالاتر با افزونه‌های زیر:
  - `pdo`
  - `pdo_sqlite` (یا `pdo_mysql`)
  - `curl`
  - `mbstring`
  - `json`
  - `openssl`
- گواهی امنیتی SSL معتبر (HTTPS برای وب‌هوک تلگرام اجباری است).
- ابزار مدیریت پردازش مانند Supervisor یا سرویس Systemd برای اجرای مداوم `worker.php`.

## ۴. دسترسی‌های ادمینی موردنیاز در کانال‌ها

ربات باید در هر دو کانال عضو شده و به عنوان **Administrator** ارتقا یابد:
1. **کانال عمومی ویرا انگلیش:**
   - دسترسی مشاهده وضعیت اعضا و لینک کانال.
2. **کانال خصوصی مینی‌دوره:**
   - دسترسی «دعوت کاربران از طریق لینک» (`Invite Users via Link`).
   - دسترسی «تأیید درخواست‌های عضویت» (`Approve Join Requests`).
   - دسترسی «مدیریت اعضای کانال».

## ۵. راهنمای گام‌به‌گام راه‌اندازی برای مدیر سرور

### گام ۱: انتقال فایل‌ها
فولدر `bot/` را روی سرور خود (مثلاً در `/var/www/viraa-bot`) قرار دهید.

### گام ۲: تنظیم فایل پیکربندی
فایل `.env.example` را کپی کرده یا مستقیماً فایل `config.php` را با مقادیر موردنظر خود تکمیل کنید:
```bash
cd /var/www/viraa-bot
cp .env.example .env
nano .env
```

### گام ۳: نصب پایگاه داده و تنظیمات پیش‌فرض
دستور زیر جداول پایگاه داده را ایجاد کرده و تنظیمات اولیه را بارگذاری می‌کند:
```bash
php install.php
```

### گام ۴: عیب‌یابی و آزمایش پیش‌نیازها
با اجرای اسکریپت سلامت‌سنجی، از صحت اکستنشن‌ها، پایگاه‌داده و اتصال به تلگرام اطمینان حاصل کنید:
```bash
php doctor.php
```

### گام ۵: ثبت وب‌هوک در تلگرام
آدرس وب‌هوک را با استفاده از متد `setWebhook` در تلگرام ثبت کنید (می‌توانید با دستور curl زیر این کار را انجام دهید):
```bash
curl -F "url=https://YOUR_DOMAIN.com/webhook" \
     -F "secret_token=YOUR_WEBHOOK_SECRET" \
     https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook
```

## ۶. راهنمای ویژه راه‌اندازی روی هاست اشتراکی (cPanel / DirectAdmin) و تنظیم وب‌هوک با مرورگر

اگر از هاست اشتراکی استفاده می‌کنید و به ترمینال لینوکس (SSH) دسترسی ندارید، تمام مراحل را می‌توانید **مستقیماً از طریق مرورگر اینترنت** انجام دهید:

### ۱. آپلود فایل‌ها در هاست
- فایل‌های پوشه `bot/` را زیپ کنید و در پوشه `public_html` (یا یک ساب‌فولدر مثل `public_html/bot`) هاست خود آپلود و Extract کنید.
- فایل `config.php` را در File Manager هاست باز کرده و مقادیر `bot_token`، `bot_username`، `public_channel_id`، `private_channel_id` و `app_url` را ذخیره کنید.

### ۲. ساخت خودکار پایگاه‌داده با مرورگر
آدرس زیر را در مرورگر خود باز کنید تا تمام جداول دیتابیس بدون نیاز به SSH ساخته شوند:
```text
https://YOUR_DOMAIN.com/index.php?action=install
```

### ۳. تنظیم وب‌هوک تلگرام با یک کلیک در مرورگر
برای ست کردن وب‌هوک دو راه ساده دارید:

**روش الف (پیشنهادی - هوشمند):**
کافی است این آدرس را در مرورگر باز کنید تا اسکریپت خودکار با توکن شما ارتباط برقرار کرده و وب‌هوک را ست کند:
```text
https://YOUR_DOMAIN.com/index.php?action=set_webhook
```
پاسخ تلگرام به صورت فارسی و گرافیکی نمایش داده می‌شود.

**روش ب (لینک مستقیم رسمی تلگرام):**
می‌توانید لینک زیر را با جایگزینی توکن و آدرس سایت در مرورگر باز کنید:
```text
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://YOUR_DOMAIN.com/index.php?action=webhook
```
نمونه خروجی موفق در مرورگر:
```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

### ۴. بررسی وضعیت یا حذف وب‌هوک با مرورگر
- برای دیدن اطلاعات وب‌هوک:
  ```text
  https://YOUR_DOMAIN.com/index.php?action=get_webhook_info
  ```
- برای حذف وب‌هوک:
  ```text
  https://YOUR_DOMAIN.com/index.php?action=delete_webhook
  ```

### ۵. تنظیم صف و پردازش در هاست اشتراکی
در هاست اشتراکی نیازی به نصب Supervisor ندارید! در بخش **Cron Jobs** در پنل cPanel یا دایرکت‌ادمین یک وظیفه زمان‌بندی‌شده ۵ دقیقه‌ای بسازید:
```text
curl -s "https://YOUR_DOMAIN.com/index.php?action=run_worker" > /dev/null 2>&1
```
همچنین تأیید درخواست‌های ورود (`chat_join_request`) به کانال خصوصی به صورت همزمان و آنی نیز انجام می‌شود.

## ۷. راه‌اندازی صف‌خوان دائمی (Worker) در سرور مجازی (VPS)
برای اجرای مداوم پردازشگر صف، یک سرویس Systemd بسازید:
```bash
sudo nano /etc/systemd/system/viraa-worker.service
```
محتوای فایل:
```ini
[Unit]
Description=Viraa Telegram Bot Queue Worker
After=network.target

[Service]
User=www-data
Group=www-data
Restart=always
RestartSec=5
ExecStart=/usr/bin/php /var/www/viraa-bot/worker.php
WorkingDirectory=/var/www/viraa-bot

[Install]
WantedBy=multi-user.target
```
فعال‌سازی سرویس:
```bash
sudo systemctl daemon-reload
sudo systemctl enable viraa-worker
sudo systemctl start viraa-worker
```

### گام ۷: تنظیم زمان‌بندی پاک‌سازی و چرخش لاگ‌ها (Cron)
```bash
crontab -e
```
افزودن خط زیر برای اجرای روزانه نگهداری در ساعت ۳ بامداد:
```cron
0 3 * * * /usr/bin/php /var/www/viraa-bot/cron.php > /dev/null 2>&1
```

## ۶. محدودیت‌های رسمی تلگرام (موارد غیرقابل‌ارائه توسط Bot API)

به دلایل حریم خصوصی و معماری پلتفرم تلگرام:
1. **مشاهده قطعی هر درس:** ربات نمی‌تواند تشخیص دهد آیا کاربری یک ویدیو یا پیام خاص را در کانال مشاهده کرده یا تا ثانیه چندم تماشا کرده است. تلگرام فقط رویداد عضویت، ارسال درخواست و کلیک روی لینک‌های ردیابی‌شده را فراهم می‌کند.
2. **ارسال پیام خصوصی به شماره‌های دلخواه:** ربات تلگرام نمی‌تواند به افرادی که تاکنون روی دکمه `/start` ربات کلیک نکرده‌اند پیام بفرستد. ارسال پیام انبوه منحصراً به افرادی ممکن است که با ربات گفت‌وگو را آغاز کرده باشند.
3. **تأیید «خواندن پیام» خصوصی:** موفقیت `sendMessage` به معنای تحویل موفق پیام به سرورهای تلگرام است، اما وضعیت خوانده‌شدن (Seen/Read Receipt) در چت خصوصی ربات از طریق Bot API اعلام نمی‌شود.
